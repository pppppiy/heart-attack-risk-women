How CardioSense works

An open look at the data, methodology, and decisions behind our women's heart attack risk model.

Data sources

CardioSense is trained on two of the largest and most rigorous public health datasets available in the United States, filtered to women only.

NHANES
National Health and Nutrition Examination Survey

A continuous survey conducted by the CDC combining interviews and physical examinations. CardioSense uses NHANES Cycle L, integrating eight data modules: demographics, reproductive health, medical conditions, body measurements, HDL cholesterol, triglycerides, fasting glucose, and blood pressure.

8 modules merged Lab values Physical exams Women only (RIAGENDR=2)
BRFSS
Behavioral Risk Factor Surveillance System

The world's largest telephone health survey, administered by the CDC across all 50 US states. CardioSense uses the 2023 BRFSS dataset. The target variable (CVDINFR4) captures self-reported history of heart attack. Filtered to female respondents (SEXVAR=2).

2023 edition Self-reported Behavioral data Women only (SEXVAR=2)

Both datasets are merged using a pd.concat union. NHANES contributes lab-measured biomarkers; BRFSS contributes behavioral and comorbidity data at population scale. Missing values are handled by per-column median imputation (numeric) and mode imputation (categorical) during preprocessing.

Features used

The model uses 20+ features across five categories, plus three interaction terms that capture compound risk effects.

Model architecture

1

Preprocessing pipeline

Built with sklearn.pipeline.Pipeline and ColumnTransformer. Numeric columns receive median imputation + standard scaling. The single categorical column (source_dataset) receives mode imputation + one-hot encoding.

2

Train / test split

80/20 stratified split on the target (heart_attack) using random_state=42. Stratification ensures the ~6% positive rate is preserved in both sets.

3

Random Forest classifier

RandomForestClassifier(n_estimators=200, max_depth=12, class_weight="balanced", random_state=42). The balanced class weight corrects for the significant class imbalance in the dataset without requiring oversampling.

4

Threshold selection

Default threshold of 0.6 was chosen by evaluating precision/recall tradeoffs across thresholds (0.2–0.7). At 0.6, the model achieves higher precision — minimizing false positives — which is appropriate for a screening tool.

Python · model training 
from sklearn.ensemble import RandomForestClassifier

rf_model = RandomForestClassifier(
    n_estimators=200,
    random_state=42,
    class_weight="balanced",
    max_depth=12
)

rf_model.fit(X_train_processed, y_train)

# Predict with custom threshold
y_proba = rf_model.predict_proba(X_test_processed)[:, 1]
threshold = 0.6
y_pred = (y_proba >= threshold).astype(int)

Limitations

Self-reported data

BRFSS relies on self-report, which can introduce recall bias and misclassification. Lab-measured values from NHANES are more reliable but fewer in number.

Class imbalance

Heart attack prevalence in the dataset is approximately 6%. The class_weight="balanced" parameter partially addresses this, but predictions should be interpreted in context of base rates.

Not a clinical tool

This model was built for research and educational purposes. It has not been validated in clinical settings or approved by any regulatory body.

US population only

NHANES and BRFSS sample the US civilian non-institutionalized population. Applicability to other countries, ethnicities, or healthcare contexts may be limited.

Missing values

Many participants have missing values for specific fields. Median and mode imputation is used, which can reduce predictive accuracy for those inputs.

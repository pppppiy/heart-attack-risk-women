CardioSense API Reference

Connect your trained Flask backend to the CardioSense frontend or integrate the prediction model into your own application.

Base URL https://your-ngrok-url.ngrok.io

Installation

Install the required Python packages in your Google Colab notebook before running the API server.

bash · Colab cell 
!pip install flask flask-cors pyngrok

After training your model, save the artifacts:

Python · save model artifacts 
import joblib

# Save after training
joblib.dump(rf_model, "rf_model.pkl")
joblib.dump(preprocessor, "preprocessor.pkl")
joblib.dump(list(X_train.columns), "feature_names.pkl")

print("Model artifacts saved ✓")

Running the server

Place app.py in the same directory as your saved .pkl files and run it from a Colab cell.

Python · Colab cell 
from pyngrok import ngrok
import subprocess, threading

def run():
    subprocess.run(["python", "app.py"])

t = threading.Thread(target=run, daemon=True)
t.start()

# Expose via ngrok
public_url = ngrok.connect(5000)
print(f"✅ API live at: {public_url}")
Copy the printed ngrok URL and paste it into the API field on the Assessment page.

        POST
        /predict
        Predict heart attack risk
      

      
Submit patient features as a JSON object. All fields are optional — missing values are imputed using training-set medians. Returns a probability score and binary prediction at the 0.6 threshold.


      
Request body

      

        

          
            
FieldTypeDescription

          
          
            
agenumberAge in years

            
bminumberBody mass index (kg/m²)

            
waist_hip_rationumberWaist circumference / hip circumference

            
systolic_bpnumberAverage systolic blood pressure (mmHg)

            
hdl_cholesterolnumberHDL cholesterol (mg/dL)

            
triglyceridesnumberTriglycerides (mg/dL)

            
fasting_glucosenumberFasting blood glucose (mg/dL)

            
poor_mental_daysnumberPoor mental health days per month (0–30)

            
diabetes0 or 1Diagnosed with diabetes

            
hypertension0 or 1Diagnosed with hypertension

kidney_disease0 or 1Chronic kidney disease

thyroid_problem0 or 1Any thyroid condition

            
menopause0 or 1Post-menopausal

JavaScript integration

      

        
JavaScript

        
const API_URL = "https://your-ngrok-url.ngrok.io";

async function predictRisk(patientData) {
  const response = await fetch(`${API_URL}/predict`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(patientData),
  });

  if (!response.ok) {
    throw new Error(`API error: ${response.status}`);
  }

  const result = await response.json();
  console.log("Risk probability:", result.probability);
  console.log("High risk:", result.high_risk);
  return result;
}

// Example usage
predictRisk({
  age: 58,
  bmi: 31.2,
  hypertension: 1,
  diabetes: 0,
  menopause: 1,
  smoking: 1,
  physical_activity: 0,
  source_dataset: "BRFSS"
});

      

    


    
    

      
Python integration

      

        
Python

        
import requests

API_URL = "https://your-ngrok-url.ngrok.io"

patient = {
    "age": 58,
    "bmi": 31.2,
    "systolic_bp": 145,
    "hdl_cholesterol": 42,
    "hypertension": 1,
    "diabetes": 0,
    "menopause": 1,
    "smoking": 1,
    "physical_activity": 0,
    "source_dataset": "BRFSS"
}

response = requests.post(f"{API_URL}/predict", json=patient)
result = response.json()

print(f"Risk probability: {result['probability']:.4f}")
print(f"Prediction: {result['prediction']}")
print(f"High risk: {result['high_risk']}")

      

    


    
    

      
Colab + ngrok setup

      
ngrok creates a public HTTPS tunnel to your Colab-hosted Flask server so the browser frontend can reach it.


      

        

          
1

          

            Create a free ngrok account at ngrok.com and get your auth token.
          

        

        

          
2

          

            Set your auth token in Colab:
            

              
Python

              
from pyngrok import conf
conf.get_default().auth_token = "YOUR_NGROK_AUTH_TOKEN"

            

          

        

        

          
3

          

            Run the server cell — the public URL will be printed. Copy it.
          

        

        

          
4

          

            Paste the URL into the API field on the Assessment page sidebar. All predictions will now route through your live model.
          

        

      


      

        
        ngrok free-tier URLs expire when your Colab session ends. Each new session generates a new URL — remember to update the API field.
